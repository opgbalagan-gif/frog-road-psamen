# FROG ROAD × PREACHER SAY AMEN

**[Играть в браузере](https://opgbalagan-gif.github.io/frog-road-psamen/)**

Портретная пиксельная аркада: лягушка в оранжевом или ментоловом худи, дорога, река, монеты и бесконечный мир.

Тап по игровому полю — один прыжок вперёд. Свайп — прыжок в выбранную сторону. На компьютере работают клик мышью, перетаскивание, стрелки и WASD. Пауза — P / Esc. Enter / Space — старт и повторный забег. После столкновения с машиной вверх поднимаются пиксельные 🙏.

Игра заполняет окно без полей и растягивания персонажей, подстраиваясь под его пропорции. При первом касании включается полноэкранный режим, если браузер его поддерживает.

После смерти появляется собственный баннер PREACHER SAY AMEN с обычной фотографией без пикселизации. Кнопка PSAMEN.COM открывает каталог, маленькая кнопка с бумажным самолётиком — Telegram бренда. PLAY AGAIN начинает следующий забег. Внешние страницы открываются только по нажатию; баннер не требует просмотра по таймеру.

Нажмите на ACID ORANGE / ACID MENTHOL в главном меню, чтобы выбрать худи. Рекорд, монеты и настройки сохраняются в этом браузере. Для игры требуется современный браузер с WebGL 2 и WebAssembly; первая загрузка получает около 38 МБ ресурсов.

Репозиторий содержит готовую веб-сборку Godot 4.6.2. GitHub Pages автоматически публикует ветку main из корня. Серверные заголовки COOP/COEP не требуются: экспорт выполнен без потоков.

Оригинальные игровые спрайты и звуки созданы для игры. Элементы PREACHER SAY AMEN добавлены по запросу владельца проекта с опорой на [каталог бренда](https://psamen.com/catalog). Промо-фотография предоставлена пользователем для баннера. Название, бренд и фотография принадлежат их правообладателям. Уведомления лицензий Godot приложены отдельно.
