# FROG ROAD — готовый веб-контейнер

Нужен установленный Docker. Распакуйте архив и выполните из этой папки:

```sh
docker build -t frog-road .
docker run --rm -p 127.0.0.1:8080:8080 --name frog-road frog-road
```

Откройте http://localhost:8080. Для публикации на собственном сервере используйте
HTTPS и обратный прокси к порту 8080. HTTPS нужен браузерному постоянному кэшу;
на localhost он также доступен. Образ собирается из официального nginx:stable-alpine.

Контейнер содержит только готовую игру. Сжатые файлы и кэш работают также на
GitHub Pages, где запуск Docker не поддерживается. Первый запуск получает движок
и игровые ресурсы; повторный использует проверенные локальные копии. При отсутствии
DecompressionStream браузер получает обычные файлы с HTTP-сжатием nginx.

Сохранения остаются в браузере. Они привязаны к адресу: прогресс с GitHub Pages
не переносится автоматически на localhost или другой домен.

Для обновления соберите новый образ из нового архива и перезапустите контейнер.
HTML проверяется на обновления при каждом открытии, файлы с хешами кэшируются
на год. Порт 8080 обслуживает HTTP, /health возвращает состояние сервера.
